Ocarina of Time Remake Randomizer

Choose your own dump of the game, pick the settings and download the mod as a .zip. Everything runs in your browser: the game file is never uploaded.

Childhood cutscenes and forced conversations are skipped (items and songs are still given). From the Temple of Time on, scenes are only shortened. Boss intros and defeats are kept.

Some key items are fixed in this version because their chest has a story event.

Shuffle

The selected Gold Skulltulas can drop any item, and their tokens are distributed among chests and other Skulltulas.

The Market Treasure Chest Game chests and those holding keys, maps or compasses do not receive key items in this version.

Every generated seed is beatable with OoTR's glitchless logic, plus a few rules where the remake is stricter.

  1. Unzip the downloaded file. It contains a Rando_<seed> folder.
  2. Copy that folder into load/0400486024DEC000/ inside Lichii's data folder (right-click the game in Lichii to open its mods folder, if offered).
  3. Keep only one Rando_* mod enabled at a time.
  4. Start a new game. An existing save does not pick up the changes.

The spoiler log (spoiler.txt) inside the folder lists where every item went.

Source code and known limitations: github.com/WekarXD/OOT-Remake-Randomizer. No game files are included.
